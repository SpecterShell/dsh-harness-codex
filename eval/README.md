# Evaluation

Benchmark suites that compare the Codex-inspired preset with DSH's Standard
preset on the same models. Each round lives in its own directory with its own
tasks, scripts and results.

- [Round 1](round-1/README.md): ten small coding tasks, one run per task,
  preset and model. 40 runs, all passed. [results](round-1/results.md),
  [analysis](round-1/analysis.md).
- [Round 2](round-2/README.md): ten harder tasks with hidden checks, protected
  files, multi-turn tasks and Workspace Write tasks, three repeats per cell.
  150 runs, 149 passed. [results](round-2/results.md),
  [analysis](round-2/analysis.md).

The numbers are summarized in [docs/benchmark.md](../docs/benchmark.md).
